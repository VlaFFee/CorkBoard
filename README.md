# Cork Boards (Forge 1.20.1)

Сборка: положите рядом gradle wrapper от Forge MDK 1.20.1 (или `gradle wrapper --gradle-version 8.1.1`), затем `./gradlew build` → `build/libs/corkboard-1.0.0.jar`.
Нужна Java 17. Для запуска из IDE: `./gradlew runClient`.

## Игра
- Креатив-вкладка «Пробковые доски»: доски 1×1 … 5×5.
- ПКМ по стене — повесить доску. Shift+ПКМ в воздухе с доской — сменить размер.
- ПКМ по доске — открывается окно доски (вид как на референсе). Чем больше доска, тем больше места.
- В креативе в окне внизу палитра из 8 видов записок: клик по записке в палитре, затем клик по доске — поставить (ПКМ/Esc — отмена).
- Клик по записке — выбрать и таскать; колесо мыши — наклон; поле внизу — текст; кнопка «Удалить» или Delete — снять.
- В выживании окно доступно только для просмотра.
- Крафт: 8 досок вокруг бумаги → доска 2×2.
- Текстуры: `python3 tools/gen_textures.py` (Pillow) перегенерирует их.
